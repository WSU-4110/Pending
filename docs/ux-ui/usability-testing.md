# Pending App – UX/UI Usability Testing

## Overview
This document outlines a usability testing plan for the Pending app's Figma prototype. The goal is to evaluate how easily users can navigate the interface and complete common tasks.

## Testing Objectives
- Evaluate the clarity of the welcome and account creation screens.
- Check whether users can easily navigate the dashboard.
- Evaluate the task creation and task management experience.
- Identify confusing buttons, labels, or navigation elements.
- Gather feedback on the overall layout and visual consistency.

## Test Scenarios

| Test | User Task | Expected Result |
|---|---|---|
| 1 | Navigate from the welcome screen to account creation | User can locate the account creation option |
| 2 | Find pending tasks on the dashboard | User can identify where pending tasks are displayed |
| 3 | Locate the option to create a new task | User can identify the Create Task button |
| 4 | Open an existing task | User can locate task details |
| 5 | Find completed tasks | User can identify completed tasks and their status |

## Testing Method
Participants will be asked to navigate the Figma prototype and complete the scenarios without step-by-step assistance.

For each scenario, observations can be recorded to identify successful navigation, usability difficulties, and possible design improvements.
